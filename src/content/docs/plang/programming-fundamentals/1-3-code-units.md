## 개요
프로그래밍 언어를 구성하는 문법적 규격과 코드를 작성할 때 사용되는 최소 단위의 구성 요소를 정리한다.

---

## 언어의 문법 규격
자연어와 마찬가지로 프로그래밍 언어도 명확한 문법 규격에 의해 작성된다. 문법 규격은 구문과 의미로 구분하여 판단한다.

### 구문 (Syntax)
코드가 언어의 형태적 약속에 맞춰 올바르게 작성되었는지 판단하는 구조적 규칙.

* 명령어의 철자, 괄호 짝 맞추기, 세미콜론(`;`) 누락 여부, 들여쓰기 등이 여기에 속한다.
* 구문 규칙을 위반하면 컴파일러나 인터프리터가 코드를 해석하지 못해 구문 오류(Syntax Error)가 발생하며 빌드나 실행이 즉시 중단된다.

### 의미 (Semantics)
문법적으로 올바른 구문이 실제로 논리적으로 타당하고 유효한 동작을 하는지에 대한 판단.

* 문법적으로는 완벽하더라도 논리적으로 불가능하거나 의도와 다른 동작을 규정한다.
* 이 규칙을 위반하면 실행 과정에서 프로그램이 비정상 종료되는 의미론적 오류(Semantic Error)나 논리적 버그가 발생한다.
* 예) `10 / 0`과 같은 연산은 문법상 오류가 없으나 수학적으로는 정의되지 않아 실행 시 오류를 일으킨다.

---

## 코드의 구성 요소
컴파일러나 인터프리터가 소스코드를 분석할 때 쪼개는 가장 작은 텍스트 단위.

### 예약어 (Reserved Keyword)
프로그래밍 언어의 문법 규격에 의해 고유한 용도와 기능이 미리 정의된 단어.

* 시스템이 이미 선점하고 있으므로 개발자가 변수나 함수 이름 등으로 임의 사용할 수 없다.

| 구분 | 주요 예약어 예시 |
| :--- | :--- |
| **자료형** | `int`, `float`, `double`, `char`, `void` 등 |
| **제어문** | `if`, `else`, `switch`, `while`, `continue` 등 |
| **기타** | `return`, `class`, `public` 등 |

### 식별자 (Identifier)
프로그래머가 변수, 함수, 클래스 등을 구분하기 위해 직접 부여하는 고유한 이름.

* 대부분의 프로그래밍 언어에서 통용되는 명명 규칙
  * 숫자로 시작할 수 없다.
  * 띄어쓰기나 특수문자를 사용할 수 없다. 단, 밑줄(`_`)은 예외적으로 허용된다.
  * 예약어는 식별자로 사용할 수 없다.

### 연산자와 구분자 (Operator & Delimiter)
연산을 수행하거나 코드 블록의 경계를 나누는 기호.

* **연산자**: 산술 연산자, 비교 연산자, 대입 연산자 등.
* **구분자**: 명령문의 끝을 알리는 세미콜론(`;`), 코드 블록을 묶는 중괄호(`{}`) 등.

### 주석 (Comment)
컴파일러나 인터프리터가 번역하지 않고 무시하는 설명용 텍스트.

* 사람이 코드의 의도와 동작을 이해하기 쉽도록 메모를 남길 때 사용한다.

### 프로그램 진입점 (Entry Point)
프로그램이 메모리에 적재되어 CPU에 의해 실행을 시작하는 최초의 시작 지점.

* 운영체제나 런타임 환경은 실행 파일이 호출되면 정해진 진입점을 가장 먼저 찾아 실행한다.
* **C / C++ / Java**: `main()` 함수에서 실행이 시작된다.
* **Python**: 파일의 첫 줄부터 실행된다.
