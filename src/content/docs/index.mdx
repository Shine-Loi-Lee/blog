## 블로그 설계 철학 : LIQUID

본 블로그는 객체지향 설계 원칙을 텍스트에 적용하여, 지식을 독립된 모듈로 정의하고 연결합니다. 불필요한 서사를 배제하고 핵심만 압축하여 전달합니다.

<CardGrid>
	<Card title="L - Linked Knowledge" icon="random">
		**연결성**: 지식은 고립되지 않습니다. 모든 부가 설명은 배제되며, 필요한 선수 개념은 링크로 참조되어 의미를 확장합니다.
	</Card>
	<Card title="I - Intuitive Interface" icon="eye">
		**직관성**: 복잡한 기승전결을 버립니다. 모든 글은 동일한 규격(정의 → 원리 → 적용)을 따라 진입 장벽을 최소화합니다.
	</Card>
	<Card title="Q - Qualitative Learning" icon="star">
		**압축성**: 방대한 양보다 구조적 밀도를 우선합니다. 예외 상황과 핵심 동작 원리에 집중해 지식의 본질적 이해를 돕습니다.
	</Card>
	<Card title="U - Understandable Explanation" icon="pencil">
		**명확성**: `단어: 정의`의 형태로 실체를 먼저 선언합니다. 모호한 비유를 배제하고 간결하고 정확하게 설명합니다.
	</Card>
	<Card title="I - Interactive Experience" icon="puzzle">
		**상호작용**: 정답만 제공하지 않습니다. 실패하는 대조군(Bad vs Good)을 함께 배치해 능동적인 사고를 유도합니다.
	</Card>
	<Card title="D - Dynamic Growth" icon="setting">
		**확장성**: 단편적인 팁이 아닌, 다른 지식과 결합하여 응용할 수 있는 뼈대(Framework) 지식을 다루며 지속 성장합니다.
	</Card>
</CardGrid>
